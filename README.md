# Command Loom

The code behind the videos on [Command Loom](https://www.youtube.com/@CommandLoom): physics simulations, satisfying builds, math and data visuals.

Every video on the channel is generated by code. No footage, no stock clips, no narration. This repository holds that code, one folder per video, so you can watch the same thing happen on your own computer and check the work.

## Videos

| # | Folder | What it shows |
|---|--------|---------------|
| 01 | [01-metronomes](01-metronomes) | 100 metronomes start at random and sync themselves on a shared, freely moving board. |
| 02 | [02-double-pendulums](02-double-pendulums) | 1,000 double pendulums start almost identically, move as one, then split into chaos. |

# Command Loom

The code behind the videos on [Command Loom](https://www.youtube.com/@CommandLoom): physics simulations, satisfying builds, math and data visuals.

Every video on the channel is generated by code. No footage, no stock clips, no narration. This repository holds that code, one folder per video, so you can watch the same thing happen on your own computer and check the work.

## Videos

| # | Folder | What it shows |
|---|--------|---------------|
| 01 | [01-metronomes](01-metronomes) | 100 metronomes start at random and sync themselves on a shared, freely moving board. |
| 02 | [02-double-pendulums](02-double-pendulums) | 1,000 double pendulums start almost identically, move as one, then split into chaos. |
| 03 | [03-fireflies](03-fireflies) | 1,000 fireflies with no leader nudge each other's flashes until they all flash as one. |
| 04 | [04-galton-board](04-galton-board) | 10,000 balls, 16 fair left/right choices each, build the bell curve. |
| 05 | [05-magnet-builds](05-magnet-builds) | Six shapes snapped together from chrome balls and stacked-magnet rods (choreographed 3D animation). |
| 06 | [06-earthquakes](06-earthquakes) | Every M4.5+ earthquake of 2025 from the USGS catalog, day by day on a globe (data visualization, frozen snapshot included). |
| 07 | [07-rainbow](07-rainbow) | Rays traced through a raindrop with measured water dispersion: why every rainbow sits at 42°, and the reversed second bow. |
| 08 | [08-pendulum-wave](08-pendulum-wave) | Sixteen ideal pendulums, one more swing per minute each, drift apart and line up again every 60 seconds. |
| 09 | [09-turing-patterns](09-turing-patterns) | Two chemicals react and spread (Gray–Scott model): spots that split, stripes, a labyrinth and holes, from the same two rules. |
| 10 | [10-same-average](10-same-average) | A fair +50 % / −40 % coin game for 10,000 players: the average gets richer while most players get poorer. |
| 11 | [11-ink-diffusion](11-ink-diffusion) | 5,000 dye molecules on random walks: why a drop spreads so slowly in still water, and why you stir your tea. |
